# VAE-based Benchmarking
This branch contains a simplified and self-contained VAE training benchmark based on the MMVAE project. It is intended only for comparing computational performance across workstations, not for model accuracy.

For setup instructions, required files, configuration, training commands, and benchmark outputs, see the [benchmarking guide](https://docs.google.com/document/d/1rF12zf3V3yNlPKxaCNPiSxPQhnoKTM1sr28EJ0xoPNQ/edit?usp=sharing). For general GPU/CPU benchmark tests, check our [wiki page](https://github.com/draeloslab/wiki/wiki/Hardware-benchmarking-for-Linux) on it
